For **Mwarokin Estates**, the best approach is **not** to start by collecting tenant data first. Instead, build your database from the **physical property outward**. This creates a scalable, GIS-enabled property management system similar to what enterprise platforms use.

## Phase 1: Register the Property (Building First)

Every property should have a unique digital identity.

**Capture:**

* Property ID
* Property Name
* Owner
* Estate
* County
* Sub County
* Ward
* Physical Address
* Title Deed Number
* Plot Number
* Building Type
* Construction Year
* Number of Floors
* Number of Units
* GPS Coordinates
* Polygon Boundary (optional)
* Building Photos
* Drone Photos (optional)
* Google Maps Location
* Building Status
* Manager

Example

```
Property
----------------------------
ID: MWR-001
Name: Green Heights
Owner: John Mwangi
County: Nairobi
Latitude: -1.2920
Longitude: 36.8219
```

# Recommended Data Collection Workflow

To keep the system organized and scalable, use this sequence:

1. Register Property
2. Capture GPS & Property Boundary
3. Upload Building Photos/Documents
4. Add Units
5. Add Amenities
6. Register Utility Meters
7. Register Tenants
8. Generate Digital Lease
9. Configure Rent & Billing
10. Enable Payment Methods
11. Activate **Lipa Mdogo**
12. Manage Maintenance
13. Monitor Financial Reports
14. Use AI Analytics & Dashboards

This property-first hierarchy ensures clean relationships and simplifies reporting:

```text
Portfolio
    │
    ├── Estate
    │
    ├── Building
    │      │
    │      ├── Floor
    │      │      │
    │      │      ├── Unit
    │      │      │      │
    │      │      │      ├── Tenant
    │      │      │      ├── Lease
    │      │      │      ├── Rent
    │      │      │      ├── Bills
    │      │      │      ├── Payments
    │      │      │      ├── Maintenance
    │      │      │      └── Documents
    │      │
    │      ├── Amenities
    │      ├── Utility Meters
    │      ├── Staff
    │      ├── Vendors
    │      └── Financial Ledger
    │
    └── AI Analytics & Reports
```

This architecture is scalable from a single landlord with one property to a national portfolio managing tens of thousands of buildings, making it well suited as the foundation for **Mwarokin Estates**.
