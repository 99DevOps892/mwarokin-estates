Go-Live Checklist — Connecting Real Payment Rails

This page is a fully working frontend. To move real money, each rail below needs a small backend endpoint holding your secret credentials — never place API secrets in this HTML/JS.

📲 M-Pesa / Airtel Money
Register on Safaricom Daraja / Airtel Money Africa, get API credentials, implement POST /api/mpesa/stkpush and a /api/mpesa/callback webhook. The landlord's paybill/till connects automatically per property once configured in your backend's property table.
🏦 Bank Transfer
Use a licensed aggregator — implement POST /api/bank/transfer and a settlement webhook.
💳 Card
Use a PCI-DSS certified processor (Stripe, Flutterwave, Paystack, Pesapal) — card fields hosted/tokenised by their SDK.
⚡ SylloPay
Call your SylloPay ledger API to debit the tenant and credit the landlord, idempotently keyed by transaction ID.
🪙 Crypto
Use a gateway (Coinbase Commerce, BitPay, NOWPayments) to generate a real deposit address per invoice and confirm via webhook.

Until those endpoints exist, this page simulates confirmation locally so you can test the full UX, receipts and real-time sync end-to-end. Every rail — mobile money, bank, card, SylloPay or crypto — charges only a flat KSh 1–5 transaction fee per rent payment, regardless of amount.
